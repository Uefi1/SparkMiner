# SparkMiner — отключение всех статусных LED

Патч полностью выключает мигание синих/зелёных/RGB статусных диодов
на ЛЮБОЙ плате. Остаётся только аппаратный красный светодиод питания.

## Что изменено

1. `src/display/led_status.cpp`
   - принудительно `USE_LED_STATUS=0` (все паттерны мигания отключены)

2. `src/main.cpp`
   - в `setup()` сразу гасятся RGB (CYD) и GPIO LED (headless)

## Как применить

### Вариант A — через GitHub (ziptogit / upload)
1. Распакуй этот zip поверх корня своего форка SparkMiner
   (файлы лягут в `src/...`)
2. Закоммить и запушь
3. Пересобери прошивку:
   ```
   python devtool.py build -b <твоя_плата>
   python devtool.py flash -b <твоя_плата>
   ```

### Вариант B — вручную
Просто скопируй два файла из архива в свой репозиторий:
- `src/display/led_status.cpp`
- `src/main.cpp`

## Проверка
После прошивки не должно быть никакого мигания статусных диодов.
Красный power LED платы останется гореть как обычно.
